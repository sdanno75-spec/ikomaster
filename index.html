途中式マスター

＝をそろえて、一行ずつ。移項・計算の順序・書き写しを、手と目で覚える。

例：
計算して新しくできた項 移項した項（符号が反対） そのまま自動で書き写した項
文字 表示 項のわく 移項の符号
＝ の位置はずっと同じ
文字 種類 問題数 解答
文字
単元 1つなら その単元だけで10問、複数なら まぜて10問
レベル

基本のルール

  • まん中の「＝」の位置は固定です。式を変形するたびに、下に新しい行が追加されます。
  • 移項：項を指やマウスでつかんで、「＝」をこえて反対の辺へドラッグします。こえた瞬間に符号が反対になります（＋ は −、− は ＋）。
  • 計算：計算したい項をタップして選び、「計算する」を押します。選ばなかった項は、システムが自動で次の行に書き写します。
  • 計算の順序：かっこ → かけ算・わり算 → たし算・ひき算。順番を守らないと計算できません。
  • 最後：「ax ＝ b」の形になったら「両辺を a でわる」で x を求めます。

計算のしかた

  • 同類項をまとめる：同じ辺にある x の項どうし（または数の項どうし）を2つ以上選ぶ。
  • かっこを外す：かっこの前の数か、かっこをタップして選ぶ（分配法則）。
  • かっこの中を計算：かっこの中の項（点線のわく）を2つ選ぶ。
  • かけ算・わり算：「3×4」などの項を1つ選ぶ。

比例式モード

  • A : B ＝ C : D の、外側の2つ（A と D）が外項、内側の2つ（B と C）が内項です。
  • 外項 → 内項 の順にタップすると、次の行に「A×D ＝ B×C」の方程式ができます（外項の積＝内項の積）。

連立方程式モード

  • 加減法：x の項・y の項・数の項が縦にそろって並びます。「①を □ 倍」で式全体（両辺のすべての項）を何倍かして、係数をそろえます。そろったら「①＋②」か「①−②」で、筆算のように合体して文字を消します。
  • 代入法：一方の式を「y＝…」の形にすると、その右辺が点線のわくになります。わくをつかんで、もう一方の式の y の上にドラッグすると代入できます。かっこは自動でつくので、かっこのつけ忘れは起きません。
  • 1つの文字の値がわかったら、その値のカードを式の文字の上にドラッグして、もう一方の文字を求めます。
  • 自分で入力するときは、2つの式を「,」で区切ります（例：2x+3y=7, x-y=1）。

設定

  • 表示：「アプリ」は色やわくで変化が分かる表示。「プリント風」は教科書やプリントのような白黒の見た目です。
  • 項のわく：項をカードのように囲むかどうか。
  • 移項の符号：「自分で選ぶ」は、＝をこえて離したときに ＋ か − かを自分で答えます（まちがえるとやり直し）。「自動で反転」は、緑の項がくるっと裏返ってオレンジ（反対の符号）になります。

プリント

  • 種類と問題数を選ぶと、A4 の問題プリント（解答つき）ができます。「印刷する」で印刷します。
  • 解答らんには「＝」をそろえるためのたての点線が入っています。
  • 問題が多いときは、書くスペースを小さくせずに2枚目に続きます。解答には途中式つきの解説がつきます。

小テスト

  • 単元（1次方程式・比例式・連立方程式）を1つ以上、レベルを1つ選ぶと、10分で解ける10問のテスト（A4縦）ができます。
  • 「段階的ミックス」は、1〜4問がレベル1、5〜8問がレベル2、9・10問がレベル3の順に難しくなります。
  • 問題は1枚に6問（左右3問ずつ）で、書くスペースを小さくしないよう2枚に分けます（連立方程式だけのときは1枚4問）。1枚目に日付・氏名・得点欄があります。そのあとに途中式つきの解答・解説が続きます。
  • 「PDF を保存」でPDFファイルに、「LaTeX をコピー」「.tex を保存」でLaTeXのソースになります（LuaLaTeX でコンパイル）。

自分で入力するとき

  • 使える記号：数字、x、＋、−、×（* でも可）、÷（/ でも可）、かっこ、＝、：
  • かけ算の記号は省略できます（3x、2(x+1) など）。負の数をかけるときは 3×(-2) のようにかっこをつけます。
  • 扱えるのは x の1次方程式です（x×x のような2次の式や、かっこの中のかっこは使えません）。
